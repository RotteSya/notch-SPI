# NotchSPI 竞品研究与 REA 拆解

观察日期：**2026-11-14，Asia/Shanghai**。研究对象：当前公开产品，以及 NotchSPI 主树 `fe4e68c9a9bd5af3d82e3f42df48cd6003f821d6`。这是产品决策研究，不是准确率评测、市场份额排名或安全审计。

## 1. 结论摘要

**NotchSPI 的竞争场域是“看着屏幕上的题目，低成本取得可理解的解答”，而不是刘海美化工具。** 当前最应该研究的三个代表性产品是 **StudyX、Gauth、Monica**：前两个争夺学习解题需求，Monica 争夺桌面截图、上下文提问和用户已有的 AI 订阅预算。日本 SPI 细分场景中，**StudyLens 的直接相关性更高，但没有足够公开规模证据称其为头部**。本研究因此保留其市场判断，并额外完成了一次 REA 网页观察。

三项最有价值的发现：

1. **首次价值与注册顺序值得优化，但 NotchSPI 已有基础。** REA 实际完成了 StudyX、Gauth 的匿名文字解题；Monica 在提交时弹出注册入口。NotchSPI 已有匿名设备账户、明确的试用领取和不扣题的引导练习，下一步应验证“练习完成 → 自己的第一道真实题”能否顺利衔接，而不是重新开发一套 onboarding。[SX-02、GA-02、MO-03，REA 证据索引](evidence-index.md)；[NotchSPI 基线](evidence/notchspi-baseline.md)
2. **答案之后的学习动作，比继续堆模型入口更值得借鉴。** StudyX 的结果页接概念、常见错误与练习工具；Gauth 接具体追问。NotchSPI 已能讲解、保存近期题目，但尚未在本次核实中发现“待复习 → 再作答 → 已掌握”的闭环。建议在现有本地历史上做小规模验证，先不扩展成课程平台。[StudyX 官方说明](https://apps.apple.com/ai/app/studyx-ai-homework-helper/id1571844479)；[GA-02](evidence-index.md#ga-02)
3. **NotchSPI 可守住的是专注的桌面流程、清楚的结果边界和可控的本地记录。** Monica 的客户端确有 Electron、截图权限检查、全局快捷键与云服务接口线索，但这不证明其更快或更稳定。NotchSPI 已有原生顶部面板、多图上下文、流式恢复、成功结果本地保存；这些能力应转化为用户能理解、能复核的体验，而不是泛化为“支持所有 AI 工具”。[Monica 静态证据](evidence/monica-static.md)；[NotchSPI 客户端契约](../../../client-behavior.md)

**建议执行顺序：真实首题完成率 → 答案依据与不确定性 → 本地复习闭环 → 计费理解度 → 有需求验证的 Windows 小范围试用。** 不建议先复制大型产品的课程库、真人辅导、视频生成或复杂模型商城。此排序是基于现状的产品判断，不是已经证实的增长因果关系。

规模依据中，Gauth 的 Google Play 页面展示 **100M+ 下载、约 2.26M 条评价**；StudyX 展示 **5M+ 下载、约 95K 条评价**；Monica 的 Chrome 商店展示 **3M 用户、约 32.4K 条评分**。这些是发行平台公开统计，不是厂商收入、月活或付费用户，也不能跨平台相加。没有可靠的同口径份额数据，因此本文称它们为**有证据支持的代表性领先产品**，不称“行业前三”。[Gauth 商店](https://play.google.com/store/apps/details?id=com.education.android.h.intelligence)；[StudyX 商店](https://play.google.com/store/apps/details?id=com.brilian.studyx.student)；[Monica 商店](https://chromewebstore.google.com/detail/monica-all-in-one-ai-assi/ofpnmcalabcbjgholdjcjblkibolbppb?hl=us)

## 2. NotchSPI 产品基线与核实范围

### 2.1 定位与核心流程

**目标用户判断：** 需要在 Mac 上阅读、练习屏幕题目，尤其涉及日本 SPI、阅读与客观题的中日英用户；这是从官网入口、界面语言、截图工作流及评测范围作出的产品定位推断，未用用户画像或付费数据验证。不能进一步声称现有用户主要是日本求职者，或者已具有某一市场份额。

核心流程是：安装 Mac 客户端 → 屏幕录制授权 → 单图/多图练习 → 用户选择领取试用 → 快捷键截取真实题目 → 官方服务或已配置通道处理 → 顶部面板流式答案与解释 → 回看成功结果。没有刘海的屏幕也使用顶部面板。[公开官网](https://notchspi-api.vercel.app/)；[源码与官网摘录](evidence/notchspi-baseline.md)

| 项目 | 代码/工程文档已实现 | 线上公开证据与本轮边界 |
|---|---|---|

### 2.2 收费与主要限制

公开日文首页显示：**试用 72 小时，每日 400 次；Plus 为 CNY 69/月、按月自动续费，每日 400 次；独立题包为 JPY 300/100 题、JPY 800/300 题、JPY 2,200/1,000 题，一次性支付。** 每日额度北京时间 00:00 重置、不结转；页面说明解释和失败不额外消耗，题包也可单独购买。本任务只核实公开展示，没有进入结账或支付；不同币种不能直接比较成“谁更便宜”。[官网](https://notchspi-api.vercel.app/)；[价格原文快照](evidence/notchspi-baseline.md)

主要限制是：Mac 平台与录屏授权门槛；Windows 尚未公开；主树和 Intel 兼容线需要分别验收；多图上限和材料生命周期；本地历史不是永久资料库；官方模式依赖网络、额度及服务端状态。已有质量工具和历史评测不能支撑当前所有语言、题型及布局的准确率声明，本文不引用旧百分比为新范围背书。[质量证据边界](../../../quality-evidence.md)

本轮仅阅读相关代码、公开信息和工程边界，没有全面审计 NotchSPI，也没有读取真实用户题目、账户凭据、数据库或生产配置。

## 3. 候选清单与重点选择

### 3.1 筛选方法

从三个实际任务出发搜索：①图片/截图解题与讲解；②日语 SPI、玉手箱及电脑端练习；③不切换应用的截图 AI 与通用学习替代。检索覆盖英文、日文、中文。先建立下表 12 个候选，再按**竞争相关性**和**市场证据强度**两条轴选择；没有把融资、媒体热度或 SEO 排名当份额。

证据分级：**平台统计**可外部核实但口径有限；**厂商自报**保留来源、不视为独立认证；**用户评论**用于提出问题、不视为代表性样本；没有可核实数据就写未知。搜索中出现的相似域名未直接认作同一产品，例如未将 `gauth.io` 的价格当作 Gauth 官方价格。

### 3.3 为什么选这三个

StudyX 提供**学习闭环**，Gauth 提供**大规模题目入口与引导式解释**，Monica 提供**桌面上下文工作流及多平台订阅竞争**。它们回答三个不同产品问题。选择不是按可下载程度排序，也没有因为 Gauth 旧域名初次访问受限就把它换掉；找到有官方关联证据的新域名后，继续完成了 REA 解题观察。StudyLens 作为细分补充，不改变规模判断。

## 4. 三个重点竞品拆解

### 4.1 StudyX：先给答案，再扩大为学习工具箱

#### 技术实现：可观察到哪里

- **直接观察**：页面发出 `getShortIdV3`、`newQueryQuestionInfo`、`solveProblem`、`ocrKeyConceptAndSplit` 等请求；请求域为 `mvp.studyxapp.com` / `mapp.studyxapp.com`。结果有题目 URL 与题目标识。**合理推断**：解题与结果组织涉及远端服务，浏览器承担交互与数学展示。[SX-02 原始网络事件](evidence/browser-observations.json)
- **合理推断**：DOM 的 `__NUXT__`、`__nuxt`、`/_nuxt/` 与 Vue 风格属性支持 Nuxt/Vue 前端判断；未识别精确版本。页面使用 KaTeX 相关 DOM，支持“数学排版组件存在”的静态观察。
- **未知**：真实模型供应商、路由与回退策略；云端数据库、保存期限、加密和删除行为；离线缓存与跨端同步实现。不能把 App Store 的旧模型营销名单当成当前请求实际调用模型。

## 6. 面向 NotchSPI 的五项优先建议

以下成本是**一名熟悉当前代码的工程师的粗略工作量假设**，不含外部设备、审核、模型费用和不可控等待；不是排期承诺。验证标准均为建议的新实验，尚未执行。

| 优先建议 | 竞品证据 × NotchSPI 当前状态 | 用户价值与最小实现 | 粗略成本 / 主要风险 | 最小验证方式 |
|---|---|---|---|---|
