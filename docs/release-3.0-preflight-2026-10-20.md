本轮针对 macOS 已公证 **3.0 build 27** 候选。后续 Windows/共享代码改动仍在工作区；它们不在该 DMG 内。没有发布 Release、推送代码、部署、修改生产变量/Stripe 设置、产生真实付款或升级付费套餐。

## 实机放行清单

保留原用户数据和旧安装包，不清空 Keychain、历史或系统权限：

1. 2.17 覆盖安装 build 27，退出再启动，核对原账户、题包余额、设置、自定义服务和历史仍在。
2. 保有录屏权限的旧安装截图成功；独立 macOS 用户拒绝后再授权能恢复，失败/取消不扣题。
3. 真实菜单与全局快捷键各只触发一次；外屏拔插、缩放、全屏 Spaces、睡眠唤醒后截图区域及浮层正确。
4. 至少一台 Apple Silicon macOS 14 验证启动、截图、公式和回看。当前系统通过不等于最低系统通过。
5. 生产恢复且兼容后端就绪后，测试老账户查题与余额结算；隔离沙箱确认开通、回跳、每日额度、取消续费和账单门户。真实生产付款另按明确授权验收，不能用模拟事件当成已收款证据。

## 上线顺序与回退

先解决数据库可用性，再部署兼容后端（保留节流，Plus 新购关闭），完成数据库/旧客户端验证，补齐支付配置并验收，启用 Plus 后验证 69 CNY/月与 400/日契约，最后发布客户端。具体变更清单见 [生产方案](plus-3.0-production-plan.md)。

发布 DMG 的资产名仍须为 `NotchSPI.dmg`；发包后核对 `/update` 和 `/dl` 指向同一 3.0 包，下载字节摘要与已公证候选一致，再完成覆盖升级验收。旧 2.18 草稿不应误发。

已有 Plus 付款后只关闭新购并保留兼容后端、webhook、门户和取消续费能力；不能回滚到不识别 Plus 的旧后端，也不能恢复旧数据库来抹去新支付记录。
