# 完整答案展开窗口

完成查题后，刘海齿轮旁显示展开图标，齿轮菜单同时提供「展开查看完整答案」。窗口只在用户主动打开时出现，不新增全局快捷键，不改变原有截图、自动提交、答案展示及复制流程。

窗口左侧按顺序显示题图，右侧显示完整答案和已有解释，两侧独立滚动。支持选择文字、复制答案、复制全部及 Esc 关闭。窗口保留打开时的题目；开始下一题、切换题组或材料失效后，旧窗口保持阅读内容，不跟随新题切换。

打开窗口不请求模型。当前题仍具备解释资格时，可使用现有「生成解释」；同题解释流同步显示，失败或中断提示未完成。旧题窗口禁用该操作；控制器另行核验题目 ID、有效期及原有请求资格，避免误用新题材料。题图文件通过原有所有权机制保留至窗口关闭。
