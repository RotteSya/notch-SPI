## 对照设计

A1 → B1 → B2 → A2；A 为 git HEAD 659e623 的原版过滤器，B 为当前增量过滤器。相同 Debug 二进制、相同新增计时与安全保护，仅切换过滤器；每次重新启动客户端、一次请求。远程进程和连接的冷状态不可控，不能称为服务器冷启动测试。4 次只能报告逐次与范围，不报告稳定 P95。

三个指标分别读取 feedbackDraw、firstAnswerDraw、renderStarted；起点为 Carbon handler 到达 screenshotTapped。保留 firstDelta/receiptApplied/responseCompleted 等阶段辅助拆分。AppKit draw 不是显示器物理扫描时间。

隔离副本与辅助应用均位于 `/tmp/notchspi-e2e-20261029/`，清单为 manifest.json；源目录及正式安装不替换。复用已有 SwiftMath/BotAvatarsKit。临时客户端使用内存 UserDefaults、临时素材目录、ephemeral credential vault，关闭匿名数据分享和自动复制，不启动更新服务。保留触发时的官方连接预热与真实素材/请求/UI链路。

新签名客户端直接读取钥匙串曾阻塞；已终止该无请求进程，改为只读辅助进程经匿名 stdin 管道向客户端传递凭据。令牌未写文件、环境变量、命令行或输出。每次启动最多一次解题请求；跨启动计数上限四次，失败不退回计数。
