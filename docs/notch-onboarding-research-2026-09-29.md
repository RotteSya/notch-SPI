# 刘海引导：案例研究与实现 · 2026-09-29

## 平台与问题

实际平台为 macOS 14+ / Apple Silicon，纯 AppKit。边缘面板是 nonactivating NSPanel，由 DisplayTween 驱动真实窗口尺寸、轮廓、内容遮罩；首次任务是捕获当前屏幕/指定应用的一道题，经现有请求管线得到答案。练习页必须在外部浏览器中显示，因为正式版截图排除本应用的窗口。

改动前本机画面和代码显示：主操作位置已固定，但截图页同时强调大快捷键、练习入口、捕获按钮；已授权还要点过连接页；练习打开后的紧凑栏隐藏了全部后续说明。原步骤切换只淡化整个说明层，快速切换可能在首次展开中改写窗口目标尺寸。前者是工程走查发现，不等同于真实新用户测试；用户困惑的程度仍需招募陌生用户验证。

## 研究材料与证据边界

检索包含中文“桌面 应用 新手引导”“Raycast 新手 引导 视频”“优秀 新用户 引导 桌面 软件”，英文“Raycast onboarding getting started walkthrough”“CleanShot X onboarding permissions”“Things Mac getting started quick entry animation”“Screen Studio onboarding permissions”。筛选后采用以下三个应用的官方任务式入门资料和演示。它们并非三个已安装并全程体验的首启向导；下面明确区分了教程、日常交互和首用权限。

### Raycast：让入门任务直接使用正式功能

- 来源：[官方 Quickstart](https://manual.raycast.com/quickstart)、[Screen Awareness 首次设置](https://manual.raycast.com/ai/screen-awareness)、[少数派中文入门资料](https://sspai.com/post/79769)。官方新手册覆盖 v2，未标明具体修订日期，访问日期 2026-09-29；中文材料日期 2023-05-12，属于旧版，不混称当前版。
- 可确认事实：Quickstart 要求唤起搜索、选择常用项目、打开动作面板、创建 Quicklink 并实际使用它。Screen Awareness 文档把权限安排在首次运行相关命令后的设置中，再配置快捷键。中文旧版资料明确提及置顶的 Walkthrough 指令。
- 采用：把主文案写成当前任务、操作和结果；保留菜单重入；已经具备权限就进入任务，不再强迫确认已完成的准备工作。
- 限制：Raycast 的搜索结果可以即时选择，本产品要读取外部题目并等待网络，不能照搬其即时完成反馈。官方嵌入 YouTube 视频返回“视频播放器配置错误”，未据此判断时长、弹性或过渡。Lazyweb 五屏预览主要为手机截图且加载不完整，未用作桌面设计依据。

### Things：同一操作面中的明确提交动作

- 来源：[官方 Quick Entry 教程及嵌入视频](https://culturedcode.com/things/support/articles/2249437/)、[Getting Productive 入门指南](https://culturedcode.com/things/support/articles/6378414/)。教程未给具体版本；演示资源目录为 frozen/2025/11，仅能确认资源路径，不能据此断言发布日期。
- 实际打开教程并播放 19.68 秒短片，观察了起始、输入文字、展开归类菜单和最后在 Family 列表保留新条目的画面。主编辑窗口中 Save 保持右下位置，展开的归类菜单依附原入口；输入的同一条内容最终成为普通列表项。教程给出唤起快捷键 → 填内容 → Save，也说明鼠标可访问选项。
- 采用：一个突出按钮承担主要任务，快捷键作为等价提示；输入/结果保留；辅助内容出现不挤走主按钮。
- 限制：这是功能上手教程与日常录入演示，不是安装全过程。保存待办是本地操作，本产品不能在请求成功前显示已完成。未从视频估算其缓动参数，未获取首启权限流程，相关项目不作推断。

### CleanShot X：结果本身成为下一步的操作对象

- 来源：[官方 Features / Quick Access Overlay](https://cleanshot.com/features)。访问日期 2026-09-29，页面未标出该演示版本/发布日期。
- 实际播放官网约 14 秒循环短片，连续观察到截图缩略图留在左下角、鼠标悬停显示 Copy/Save、拖动的缩略图沿路径进入聊天窗口，以及结果留在聊天中。浮层承载实际产物，没有额外成功说明页替换它。
- 采用：真实截图和答案沿用日常组件；成功只改变上方状态，内容保持原位置；完成时整组收回，收完再切日常布局。
- 限制：这是官方操作演示，不是完整首启录屏。悬停才出现动作不适合本产品的新用户，因此主按钮始终可见；不照搬悬停隐藏。未确认其权限引导，不声称它采用特定权限策略。演示有后期镜头，不能据此反推原生动画速度。

以上没有可信完成率/转化对照数据，本轮不做提升幅度声明。Things 和 CleanShot 的动态判断来自已播放的官方视频，不来自静态截图；只迁移可观察的空间关系，不推断原厂时长。

## 统一设计

| 问题 | 采用依据 | 实现 |
|---|---|---|
| 不知道当前应该点哪一个 | Things 的单一明确提交动作 | 固定蓝色“截图并查题”；快捷键变成小号等价提示；“没有题目？打开练习题”降为辅助入口 |
| 准备工作与真正开始混淆 | Raycast 的任务式首用设置 | 已授权欢迎后直接查题；未授权说明用途再请求；拒绝保留设置入口和恢复说明 |
| 离开刘海后丢失操作线索 | Things 的稳定操作位置 | 练习页打开后留 210 pt 操作栏，按钮和一句明确结果预告仍可见 |
| 整页替换难以理解变化 | CleanShot 的产物连续性 | 说明离场与入场分开，按钮原地；截图/答案成为真实日常内容，完成时保留到收起结束 |
| 快速点击时可能跳变 | 本项目窗口动画实现走查 | 展开中变更目标、反向操作从当前窗口矩形重新起算；单次操作即时执行，双击第二次和长按重复不穿透 |

每步保留单一主要动作。已授权路径为欢迎 → 实际查题 → 完成；未授权在查题之前插入权限步骤。仍保留快捷键、自己的题目和练习页，不强制使用练习页。关闭保存检查点，只有实际成功后的完成动作持久化完成。练习页打开失败留在查题页原位重试，不再进入伪工作状态。

## 动效规格

- 首次展开：从真实刘海框开始，380 ms 无超调缓出；容器达到约94%的目标几何尺寸后，内容才以平滑透明度出现，避免完整宽度的文字和按钮在狭窄窗口中被裁切。主动作可见后可立即操作，不等待动画结束。
- 步骤切换：按钮/辅助操作保持自身实例；旧说明快照90 ms退去，新说明延后100 ms开始，以220 ms、6 pt位移和透明度落定，返回反向。只保留一份不可点击、不可朗读的旧快照；下一次变化清理上一份。欢迎流程图在切换开始时立即移除，避免残影与新出现的练习入口重叠。
- 按压：主按钮收至98.2%，75 ms压下、160 ms回到原位，动作即时发生；不使用大幅弹跳。键盘/辅助功能触发亦有反馈，忙碌时按钮呈不可用状态。
- 工作 → 成功：标题和主按钮更新，截图与答案的起点保持一致；成功不另开页面。完成收起260 ms，容器采用起止平缓的五次缓动；内容在前26%的时间内先淡出，随后容器明显缩小，原内容保持布局，遮罩收完再退回日常排版。下一次展开仍有答案；收起态也支持直接点击，避免依赖鼠标重新进入的悬停事件。
- 减少动态效果：直接显示目标状态，无说明位移/快照；按钮不缩放。DEBUG且隔离运行时可用 `NSPI_QA_MOTION_SCALE` 放慢同一路径以检查中间态，不影响Release。

以上时长是本项目设计参数，不是案例测量值；实机检查与限制记录在下文。

## 运行与交付

在native目录运行 `./scripts/onboarding-qa.sh --mock -appLanguage zh-Hans`，构建并运行独立QA应用和本地mock。它只验证界面与传输流程，所有题目返回固定答案，不能用来日常查题。正常本机使用请退出QA后运行 `./scripts/run-local.sh`：构建当前代码，沿用正常账户与所选服务，不强制重新引导。查看慢速动效可在mock命令前加 `NSPI_QA_MOTION_SCALE=6`；检查拒绝/减少动态效果分别用 `NSPI_QA_ONBOARDING_DENIED=1` / `NSPI_QA_REDUCE_MOTION=1`。这些开关仅DEBUG且隔离QA生效。

修改前基线提交为 `c8a95e2`。本轮实现保留工作区便于审阅，未推送或发布。

## 后续：将练习准备与查题操作拆成两步

原先“打开题目”和“截图查题”混在同一页，练习题只是较弱的辅助入口。现在已拆为两个可恢复的状态：第一步以“打开练习题”为唯一主操作，成功调用默认浏览器后才进入第二步；第二步在固定操作行同时展示“按 ⇧⌘1”和“点击查题”，答案结果仍在下方接续。练习页打开失败停留在第一步并提供重试；返回顺序为截图查题→打开练习题→欢迎，截图时若权限被撤销，完成授权后会回到截图步骤。

第一步高248 pt，容纳用途、浏览器结果预告和失败恢复；第二步收至220 pt，只保留操作与结果预告。主按钮在两个步骤仍保持x=宽度−262、y=98。引导状态测试19项通过；本机隔离QA实际完成欢迎→打开本地练习页→点击查题→本地mock答案。关键截图为 `21-practice-step.png` 与 `22-capture-step.png`。
