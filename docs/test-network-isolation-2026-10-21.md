# 测试网络隔离与统计排除

> 历史记录时点：2026-10-21。本文的“当前”“最新”、部署状态、测试计数与待办均指对应记录时点，不代表 2026-10-23 的线上状态；本次整理未重新核对生产。

## 原因与范围

设置页测试打开真实账户页时，没有设备凭证会调用注册。`NSPI_QA_EPHEMERAL=1` 只隔离凭证，并不阻止默认生产地址。版本取自当前进程 Bundle；本机 `com.apple.dt.xctest.tool` 的版本是 `16.0`，与疑似测试账户一致。11 个注册时刻落在保存的测试运行区间，另 1 个紧邻测试启动；其余账户来源不能逐个确认。

`Package.swift` 为 `NotchSPITests` 增加 `TestNetworkIsolation` C 依赖。单个 C 对象的加载构造函数在测试执行前调用 macOS 自带 sandbox API：拒绝网络操作，仅允许本机回环 IP 的绑定、入站和连接，并拒绝系统配置及环境变量指定的代理端口。所有 XCTest 用例、后台 URLSession 请求及子进程受到同一约束；不依赖测试排序、筛选或 `NSPI_QA_EPHEMERAL`。沙箱建立失败时终止测试，不降级为联网运行。该 API 已被 Apple 标记弃用，未来工具链不支持时应保持失败关闭，并替换实现。

`DevelopmentIsolation` 通过 XCTest 主程序身份或已加载 `.xctest` bundle 识别测试进程。`OfficialAPI.baseURL` 在测试中仅接受既有的显式回环服务地址，否则回到无服务的 `127.0.0.1:9`；`readAccountHTTP` 再次核对目的地址，公开主机名和 IP 在进入 URLSession 前失败。正常 App 不满足测试进程条件，保留原服务地址和请求行为。

此依赖仅由测试目标引用，正式可执行文件不链接它。不安装工具，不修改系统沙箱、网络、shell 或浏览器设置。测试中需要网络的接口继续使用回环 HTTP peer。历史冻结源码和其他 checkout 不自动获得此修复，运行旧副本测试前须同步本次测试依赖或显式使用同等的进程网络沙箱。

初版只限制回环网络时遗漏了系统代理：本机代理监听 `127.0.0.1:1082`，URLSession 可经它转发到生产。验证期间由此创建了 ID 96–99 四个账户，时间分别为北京时间 16:34:52、16:35:55、16:41:28、16:42:49，均对应本次测试。发现后增加代理端口拒绝和官方请求入口检查；不能把初版沙箱专项通过当作整体隔离通过。

## 验证

验证日志存放于 `output/test-network-isolation-2026-10-21/`。隔离专项覆盖加载前初始化、内核拒绝公网连接和已配置代理端口、子进程继承限制、本机 HTTP 可用且重定向不能逃逸、官方公开注册地址在发送前被拒绝。修复代理遗漏后，82 项专项回归通过；不设置 QA 隔离变量时，7 项网络隔离测试同样通过；统计与内部排除相关的 31 项服务端测试通过。
