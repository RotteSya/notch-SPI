# 新手引导视觉与动效打磨 · 2026-10-16

## 设计与实现

在现有未提交的新手旅程改动上完成本轮视觉重构。保留用户此前恢复的中日英引导措辞；`copy` 函数与本轮开始前备份逐字比较一致。

- 用原生 Core Graphics 绘制可缩放的微型屏幕、刘海、题纸与截图取景框。单图、多图和权限有各自的视觉状态，示意图只作装饰，不进入辅助访问或拦截点击。
- 说明卡采用有界文字列、25pt 半粗标题、13pt 正文、11pt 辅助说明。保持现有正式答案卡的边界与材质，统一底部细分隔线、38pt 动作高度和左右对齐。按钮宽度适应三语及自定义快捷键，返回和语言入口减轻视觉权重。
- 页面交接使用 240ms 整体内容淡变，示意图有 560ms 单次进入动作；读题期间没有装饰性循环动画。响应系统减少动态效果设置。
- 操作行跟随面板真实显示高度，避免页高切换时按钮提前跳到最终位置。较长权限说明在空间足够后进入，示意图和标题始终保留，消除过渡中的整页空白。
- 收缩期间同步父视图点击范围，修复最初几帧按钮可见但不能点击的缺陷。文字尺寸测量按内容和宽度缓存，避免逐帧创建文字测量控件。
- 练习网页改为浅色题纸与独立操作说明栏，使用清楚的材料/问题切换、键帽和窄屏堆叠。短视口调整上方留白，保证题目与选项完整可见。

用户指出图案与NOTCHSPI的高度不一致。根因是图案使用日常页23pt中心，文字位于引导页20pt中心；图案16pt画布里的可见轮廓也略大。将图案、品牌、右侧操作统一引用引导20pt中心，并将引导图案画布调为14.5pt。日常界面仍保持23pt中心和16pt图案，原有呼吸、旋转和展开收起行为保留。
