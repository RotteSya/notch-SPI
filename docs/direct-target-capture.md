# 一键捕获目标 → 飞入刘海

2026-09-13。在现有 AppKit 项目中，将 ⌘⇧1、⌘⇧2、⌘⇧9 及对应菜单入口统一为完整目标捕获。手动选区工具仍供旧的显式选区路径使用，但这三条入口不再创建选区窗口、等待鼠标、裁剪或二次 JPEG 编码。

## 实现

- 触发时冻结配置目标、主屏 ID、前台应用及指定应用的 WindowServer 窗口 ID；截图、指纹与来源坐标绑定同一次操作。ScreenCaptureKit 列表不再被误当成窗口层级顺序，目标消失后不会改截另一份文档。
- 捕获结果附带 AppKit 全局点坐标。Quartz 坐标使用主屏高度翻转；负坐标和不同方向的副屏不乘 Retina 像素倍率。指定应用优先枚举可见窗口，找不到锁定目标时才查询离屏窗口。
- 按键反馈先显示正在捕获并轻量响应。成功图从实际来源矩形沿弧线收缩至按图片比例计算的卡槽；图片视图显式缓存，异步解码后可正确更新。
- 编码、素材哈希/文件录入和缩略图解码在后台执行。录入成功即更新轮次和计时；飞行完成不阻塞提交和下一张录入。动画面板继续鼠标穿透、不可激活；减少动态效果时只在落点渐显。
- 多图继续最多 4 张，单张无限等待，第二张起最后一次成功录入后 4 秒自动提交。实际捕获期间暂停，失败恢复剩余时间；整轮取消校验迟到回调并清理任务。
- 设置、引导、等待、错误文案改为捕获已配置目标。若目标包含多道题，提示先在目标窗口只显示一道题再截图。

## 验证边界

全局 Carbon 组合键的物理投递未实按核验；通过共享入口、菜单和自动化验证角色映射。实机使用单显示器指定应用目标，真实多屏、最小化窗口、全屏目标和系统减少动态效果的动态观感仍需实机验收。几何与减少动态效果分支已自动化验证。

当前 UI 工具只能读取窗口状态和静态截图，没有取得完整桌面飞行动效录屏，因此不把状态截图作为录屏。Codex 应用快照参考受工具访问限制，参考动画未核验。
