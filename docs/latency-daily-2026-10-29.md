## 耗时归因与限制

- 按键到提交约 0.38–0.48 秒；后台请求准备约 15–58 ms；首片段到首答案绘制约 31–147 ms。它们不是本组多秒等待的主要来源。
- 服务端请求全程通过响应的 x-vercel-id 精确匹配生产日志，包含认证、数据库、供应商网络/处理/生成和结算，不能叫作纯模型计算。
- 客户端提交到完成回调减去服务端全程，混合残差分别为 2.333 / 1.001 / 3.523 / 3.462 / 3.813 / 4.292 秒。它包含本地准备、上传、平台入口、回程、解析等，不能全部归因于代理。
- 六次均记录到代理连接并复用连接。DNS/TLS 缺失不填零。极短的额外 transaction 不等于第二次收费请求；每次额度回执仅一次。
- `response_receive_ms` 不能全部解释为答案正文下载时间：SSE 长连接中的等待也落在该区间。正式服务尚无 provider 分段记录，因此供应商排队/计算与服务端事务仍不能精确拆分。
- Q9/Q11 的计量输出较多且服务端全程更长，支持优先调查上游首答案等待；这不是输出 token 全属于可见正文或纯推理时间的证明。
