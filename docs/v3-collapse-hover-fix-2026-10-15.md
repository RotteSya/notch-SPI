# 手动收起与悬停恢复修复（2026-10-15）

用户反馈：收起后需等待才能通过悬停展开；放置一段时间后收起按钮偶尔需要多次点击。

针对代码中可确认的冲突路径修复：
- 根视图此前每次布局更新都移除并重建鼠标追踪区域；现在保留同一个inVisibleRect区域，由AppKit跟随尺寸变化，避免动画反复产生旧几何下的进入/离开事件。
- 手动收起同时清空控制器与视图的旧悬停状态，取消待执行的自动收起任务。
- 收起中/收起后只把最终紧凑刘海frame视作悬停展开目标；原收起按钮位置的迟到事件不能反转关闭。使用当前指针位置处理进入、离开和移动，不设置任何等待冷却时间。
- 明确启用面板鼠标移动事件；顶部控件声明needsPanelToBecomeKey=false，保持不抢焦点并允许第一次点击。

验证：新增两项回归，覆盖20轮关闭后的旧位置事件拒绝/紧凑区域立即返回/追踪区域身份稳定，以及非键盘焦点面板的10轮控件按下抬起一次一响应。原生QA通过辅助访问点击收起、再展开，答案与四图保留。

边界：CUA坐标点击返回AXError.notImplemented，不能完整重放真人鼠标扫过的时序；不把辅助访问点击等同于物理指针复现。本轮无模型调用。保留快捷键、自动提交、刘海安全几何与点击数，不推送、不发版。

首轮新增测试仅因把AppKit附加追踪区域计入总数而失败；改为检查自有mouseMoved区域的数量和身份，保留首轮记录。
