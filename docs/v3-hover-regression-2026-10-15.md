# 悬停回归修正

用户反馈上一轮修复后，悬停展开不足一秒便收起，移出又展开。本轮仅调整悬停判定，不修改动效参数或增加延迟。

- 展开期间不再使用每帧变化的 window.frame 作为鼠标边界，改用最终展开区域与紧凑入口的并集。
- 包含屏幕最顶边，避免 NSRect.contains 对 maxY 的排除使顶边被当作离开。
- 鼠标 exit 事件不能发起展开；正常 enter/move 可立即重新展开，无冷却时间。
- 保留手动收起清理状态、旧按钮位置不反转关闭、控件首击响应。

新增真实 NSPanel 附着视图回归，覆盖 21 个过渡帧、提前进入展开内容区域、停在屏幕顶边、实际离开、收起后旧 exit 不重开、正常重入立即展开。专项 3 项通过；完整 warnings-as-errors 检查 502 项，4 跳过、0 失败。测试日志 `/tmp/notch-hover-stable-tests.log`。

验证边界：以上是窗口与事件处理的自动回归，不能代表真人物理鼠标实测。当前 CUA 无移动鼠标接口，上一轮坐标点击返回 notImplemented；未以 AX 点击或固定展开 QA 预览冒充悬停验收。上一轮的 501 项检查漏掉此动画中的窗口边界路径。

快捷键、自动提交、物理刘海安全布局及查题点击数均未修改，无真实模型调用、推送或发版。本机沿用版本 2.17/24。

本机更新：arm64 Release 构建完成，Developer ID + hardened runtime 签名及验签通过；正常包 `dist-qa/NotchSPI.app` 已启动，单实例 PID 53707，无 QA 参数。构建日志 `/tmp/notch-hover-stable-build.log`。
