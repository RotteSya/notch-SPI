# 3.0 刘海菜单实弹与深浅色复核

本轮仅本机体验，保留 2.17/24；不推送、不发版。

## 修改

- 原生菜单从刘海齿轮下方弹出，不再依赖鼠标位置。将 popup 关联刘海视图，使原生菜单与控件的辅助访问关系完整；实际检查已能读取菜单并从「设置…」返回设置窗口。
- 菜单使用屏幕可用范围，并避开 safeAreaInsets 顶部硬件区域，四周保留 6pt。仍用 AppKit 原生深浅色材质、选择反馈与开关动效。
- 设置侧栏的悬停、键盘焦点和选中背景统一为 12pt 圆角。修正 DEBUG 慢速检查中 spring duration 与 speed 重复放大时长的问题；正常时长不变。
- 人物像列表增加 18pt 圆角裁切，修复选中行背景超出卡片圆角。
- settings 离线 QA 场景展开刘海，增加仅 DEBUG 的深浅色切换和实际菜单触发入口，便于重复验证；不进入正常发行包。

原有快捷键、自动提交、菜单动作与直接查题入口保持不变；没有新增查题点击或菜单层级。未调用模型、未修改正常用户偏好。
