# 刘海内新用户引导 · 2026-09-29

本次在 `native` 工作区接入 macOS 14+ / Apple Silicon 的 AppKit 实现，保留开始工作时已有的修改。未执行远端发布、生产配置变更或替换 `/Applications/NotchSPI.app`。

## 设计与真实功能衔接

原独立六页窗口的入口改为现有 `NotchPanel` 中的三个阶段：认识捕获与回答、理解屏幕访问和数据用途、完成一次实际查题。引导共用日常刘海的轮廓、Rose 标识、蒙版、显示刷新时钟与高度弹簧；操作阶段收紧为顶部说明，下方保留真实截图和原答案渲染器。完成时内容向上归位，恢复日常标题和操作，不丢弃答案。

欢迎与捕获说明高 354pt，权限说明按内容展开至 404pt；工作及成功状态的说明区缩至 160pt，再根据截图、答案自适应高度。正文不随窗口形变重新换行；步骤使用可替换的短淡入，完成后的内容移动从当前呈现位置重新定向。减少动态效果时直接落到终态。

权限只在用户点按时申请，返回应用后轮询实际授权状态。macOS 的权限提示和系统设置必须由系统窗口承接。练习题是本地浏览器页面：应用本身的窗口按工程约定排除于生产截图，不能把应用内题卡作为真实截屏素材。练习页不预填答案，捕获、注册、提交、流式回答与结算均走日常链路；用户也可以直接捕获自己的题目。

## 状态与入口

- 返回、跳过权限说明、稍后继续、Escape 关闭均有明确路径。
- 关闭保留检查点并停止自动弹出，不冒充完成。刘海设置菜单可继续；应用获得焦点时可用 `⌘⇧G` 重入。
- `onboardingDone` 保持旧安装兼容；`onboarding.v3.step` 保存步骤，`onboarding.v3.dismissed` 保存主动关闭，`onboarding.v3.firstSuccess` 区分首次成功。
- 重启中的工作或成功展示只恢复到操作说明，避免恢复没有执行者的加载状态。
- 成功仅从真实请求完成回调进入；`retake`、无答案和失败不算成功。退出后的迟到回调不会重新打开引导。
- 截图过程中重复操作由现有单次执行门控拒绝；取消、目标/账户上下文失效返回操作说明；失败可重新捕获。
- 成功后点“完成”或“收起”持久化完成状态，答案继续使用原渲染器。已完成用户不在更新时自动重播。
- 支持中、日、英即时切换；沿用可聚焦、带辅助功能语义的控件，显式支持 Tab / Shift-Tab 循环，无需打开系统完整键盘控制。引导外恢复面板不抢键盘的行为。

## 本地启动

从 `native` 运行：

```sh
./scripts/onboarding-qa.sh --mock
```

该脚本构建独立测试 bundle、启动内存 mock 服务，并强制展示引导。使用独立 UserDefaults 域、进程内凭证和 DEBUG 临时观测日志目录；退出测试应用时关闭自己启动的服务。可用 `NSPI_ONBOARDING_PORT` 更换本地端口。已有正式版仍可运行；若占用相同快捷键，使用引导内捕获按钮。

```sh
NSPI_QA_REDUCE_MOTION=1 ./scripts/onboarding-qa.sh --mock
NSPI_QA_ONBOARDING_DENIED=1 ./scripts/onboarding-qa.sh --mock
```

直接运行发行构建会使用常规产品通道。测试应通过上述脚本启动，不应将 mock 结果表述为正式模型验收。旧 `OnboardingWindow.swift` 中已有改动予以保留，但应用启动不再实例化该窗口。
