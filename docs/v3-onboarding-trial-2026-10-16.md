# 多图成功文案与三天体验引导

## 页面与流程

多图成功页正文按用户指定替换为“成功了！除此之外还有自动模式和性格测试模式，欢迎您自行探索。”，日文、英文同步。保留箭头，按钮改为“继续”，进入独立的免费体验领取页。

体验页沿用 13pt 正文、0.72 白色、3pt 附加行距及 12pt 段落间距，新增原生绘制的三张日历示意。覆盖检查中、可领取、领取中、已领取、失败、未开放、已到期和无资格八种状态。等待时禁用重复提交；失败可重试，跳过可完成引导，稍后继续保留体验页检查点。进入体验页即清除练习答案与题图，不要求重新完成截图练习。已领取显示服务端的实际到期时间。

账户页增加延后领取入口、当日剩余次数和到期时间，三语说明同步。领取不打开浏览器、不创建支付订单。正式服务未提供新契约时显示“3 天免费体验暂未开放”，不能用旧的一次性 30 题回执冒充三天体验。

## 用户确认的额度规则

用户先确认每日 600 次，随后明确调整为每日 400 次，其余额度规则沿用。实现 `trial3d400-2026-10-16`：首次领取起连续 72 小时，北京时间每天 00:00 重置 400 次，不累计；首尾自然日按剩余时间使用。low/high/max 及各模式共用，成功解答计一次，失败不计；已有协议内解释、恢复及幂等重试不额外计次。360 次开始提醒，日额度用完或体验到期后可继续使用已购题数。

使用现有匿名设备身份识别资格：开关开启后新注册的设备可领取一次，旧账户不补授。领取将未用的首次 30 题赠送换成当日 400 次；跳过保留原余额，付费/人工赠送额度不受影响。并发领取不重复授予、不延长有效期。

服务端 Memory 与共享 SQL 账本实现资格、72 小时时间窗、每日 lot、持有/结算和到期撤销；SQLite/Postgres 增加 `free_trials` 表和 lot 到期列。所有时间和准入由服务端判定，跨日旧请求失败释放不计入新日；有效请求的结算继续遵循已有租约。账户、SSE 和状态接口返回同版本权益快照。客户端严格验证回执并绑定服务地址、设备、身份代次和余额版本，拒绝账户切换后的迟到结果。

接口及上线规则见 [官方契约](official-api.md)。2026-10-16 已按用户授权部署正式服务并持久开启 `FREE_TRIAL_ENABLED=1`；有效体验和未结算持有存在时不能回滚到旧账本服务。完整部署身份、源码核对、生产额度检查及边界见 [每日 400 次上线记录](free-trial-400-release-2026-10-16.md)。
