# 客户端行为

当前 macOS 客户端的稳定行为。修改入口和测试名写在每节末尾。持久化字段的删除条件见 [compatibility.md](compatibility.md)。

## 截图与多图

热键在 `Sources/NotchSPI/Settings/Settings.swift`：⌘⇧1 讲题，⌘⇧2 多图（持久化键名仍是 `context`），⌘⇧9 人格测试，⌘⇧0 自动模式，⌘⇧Space 显隐。⌘⇧3–6 留给系统截图。

一次捕获读取当前目标的完整画面。预览打开时暂停提交，关闭后重新开始 4 秒倒计时。多图收集 2–4 张，最后一张成功后 4 秒提交；只有一张时继续等待。每张可以删除，删除后 8 秒内可以撤销。取消和迟到回调不得把过期图片送出。

测试：`ScreenshotRoundTests`、`ScreenshotIntakeTests`、`CaptureFlowStabilityTests`。

## 引导

启动进入 `NotchController.showOnboardingIfNeeded()`。欢迎页用 `NSPopUpButton` 切换简体中文、日本語、English，辅助功能标签为 `Language / 语言 / 言語`。体验页领取 72 小时、每日 400 次成功求解，北京时间零点重置。可选择「稍后领取」完成引导，资格不因跳过或时间推移消耗；以后在设置 → 账户与订阅主动领取，领取成功才开始 72 小时计时。已完成或已收起的引导保持原状态，菜单可以重放。减少动态效果由系统设置决定；DEBUG 下 `NSPI_QA_REDUCE_MOTION=1` 强制开启。

`onboardingDone` 与 `onboarding.v3.dismissed` 继续表示完成和收起。

测试：`NotchOnboardingTests`、`OnboardingJourneyTests`、`OnboardingBoundsTests`、`OnboardingAccessibilityTests`、`OnboardingMotionTests`。

## 答案、公式与 Ghost

刘海流式展示答案。公式使用 SwiftMath 1.7.3，字体 bundle 随调试包和正式包交付。等待状态由 `GhostIndicator.swift` 绘制，源码来自 `Vendor/BotAvatarsKit`。长文本在刘海内换行；悬停展开，离开或主动收起后回到刘海。带刘海的机型避开硬件区域。

Release 构建排除本应用窗口的软件截图。DEBUG 只有显式 QA 开关可以放开。

测试：`ManualCollapseHoverTests`、`HardwareNotchLayoutTests`、`AnswerMathTests`、`GhostIndicatorTests`。

## 最近查题

合格的成功结果进入本机最近查题。回顾已保存的题目不再提交新请求。`NSPI_QA_EPHEMERAL=1` 时最近查题和遥测使用开发空间。

测试：`RecentQuestionTests`、`CaptureFileLifecycleTests`。

## 本地题库

本地题库入口、导入、检索和本地答案流程已经移除。Application Support 中的旧题库文件保持原样，当前应用不再读取。截图查题走已选择的官方服务、自定义 API Key 或本机 CLI。

## 三通道

新安装默认官方服务。自定义 Key 与本机 CLI 仍是产品通道。隔离开发包使用独立 bundle、空偏好、`-official.baseURL` 和 `NSPI_QA_EPHEMERAL=1`，从而走 loopback 上的 official mock。

账户、重试、401 和流恢复：`OfficialAccountStateTests`、`OfficialCaptureRunTests`、`OfficialStreamTransportTests`。

## 应用内更新

`UpdateChecker` 继续通过 `/update` 检测版本；用户点击「立即更新」后由 `InAppUpdater` 从 `/dl` 下载，窗口显示已下载大小及已知总大小的进度。下载完成后自动验证、安装并重启，无需打开浏览器或手动退出。更新期间重复检查不会发起第二次下载。

安装仅支持可写目录中的已安装 `.app`，拒绝磁盘映像、App Translocation 和未打包运行。更新候选必须是同一正式 bundle ID、符合当前应用的签名身份要求、通过系统安全评估，且版本高于当前版本、不低于检测到的版本。正式更新下载只使用 HTTPS，重定向也不能降级。验收可通过本次启动参数 `--update-test-base-url http://127.0.0.1:<port>` 指定回环测试源，仅接受显式 IPv4 回环地址和端口，HTTP 重定向不得离开该源；签名和版本校验保持相同。该参数不写入偏好，不改变账户服务，重启后恢复正式更新源。未签名开发包不能用于真实更新验收。

新版先复制到安装目录同卷的私有暂存目录并校验，再通过主 RunLoop 请求应用正常退出，沿用记录落盘和临时截图清理。退出请求不得直接嵌套在主 DispatchQueue 回调里，以免 AppKit 的 terminateLater 事件循环阻塞 MainActor 清理任务。独立安装进程最多等待退出 60 秒；退出被拒绝时保留旧版并报错。替换或启动命令失败时回退旧应用；失败暂存目录保留用于恢复。下载阶段可取消。安装后通过 --update-ready-file 等待新版在正常初始化和主事件循环运行两秒后确认；确认前退出会恢复旧版。若新版仍运行但 60 秒内未确认，则保留暂存和旧版备份，不覆盖运行中的程序；不能保证运行数分钟后的稳定性。收到启动确认才清理暂存目录。账户与设置目录不参与替换。

发布前仍需用两个 Developer ID 签名、公证的版本实测下载、安装、重启和系统权限保留。已有浏览器下载逻辑的旧版必须先安装一次支持本流程的客户端。此改动不发布服务端或安装包。


## 设置中的账户与订阅

设置保留通用、快捷键、账户与订阅、人物像、服务与模型五个入口。Plus 为账户页中的订阅卡片，和可用额度、一次性题包、设备信息处于同一滚动页面；`notchspi://plus` 与账户回跳落在同一缓存页面，切页保留滚动位置。购买入口没有默认回车快捷键。取消续费使用窗口内确认，默认按钮为保留订阅。

订阅未获取、同步中、未开通、待付款、已到期与已取消续费分别展示；未获取状态不会被呈现为未开通。Plus 进度条跟随强调色，卡片适配明暗主题与增强对比度，导航保留键盘及减少动态效果支持。离线界面样例用 `NSPI_QA_BALANCE=120 ./scripts/design-qa.sh settings`，仅展示模拟额度，不代表真实账户。

账户总览优先说明下一题的额度来源，按免费 / Plus / 其他赠送余额 / 已购题包顺序使用；每日额度和长期题包分别展示，不能将快照总额与 Plus 再次相加。关闭「自动使用已购题包」后，客户端请求携带 `allow_purchased_credits: false`，服务端在同一扣费事务中排除已购题包；来源快照缺失时显示待核对，服务端不支持保护能力时拒绝受保护的官方解题请求。

恢复码是账户凭证，只在用户主动查看时显示；恢复现有账户先用候选凭证获取并验证账户快照，验证成功、服务地址和原账户未变化时才替换凭证。失败保留原账户。恢复不合并账户余额，切换前提示保存当前恢复码。

本机交互预览入口为 `output/settings-product/启动本机体验.command`。使用隔离的临时客户端账户与内存服务，模拟订阅付款、续费失败、取消续费与额度耗尽；不连接真实支付和模型服务，不修改正式安装，不发布。退出重开客户端会创建新的临时账户。


设置视觉修订：统一 12pt 卡片圆角、页眉说明和表面边框；账户来源用四列数字展示。Plus 卡片根据状态与提示消息收合，父级同步重排后续内容。按钮保留 NSButton 的键盘、辅助功能与 target/action，使用统一明暗表面、悬停和按下态。侧栏选中态在目标位置淡入，避免跨越其他条目；减少动态效果仍直接切换。人物像为空时提供直接创建入口，有数据后恢复列表与编辑器。切换语言同时刷新侧栏标题。本轮本机预览和截图记录见 output/settings-craft/，未发布。

### 设置版式更新（2026-10-17）

通用页使用编号分区、三档思考选择与双列捕获设置；思考选项支持方向键、空格和回车。账户页取消大块容器卡片，统一为体验、订阅计划、额外用量和账户恢复四节。未开始体验时显示 3 天体验说明与开始按钮，不展示零余额仪表。设置面板不提供截图查题动作。

设置下拉框与开关使用统一自绘表面：浅色/深色、悬停、按下、禁用、选中及键盘焦点分别反馈。下拉列表保留原生菜单；辅助功能激活后焦点留在控件，Tab 继续移动。开关整行可点击，空格/回车切换；禁用时拒绝激活。账户页题包策略使用同一组件并继续由服务端确认保存。

快捷键、通用、人物像和服务与模型页沿用编号分区与统一控件。快捷键录制采用平面键位展示；离开页面或关闭设置窗口会取消录制，避免本地按键监听残留。通用页的行为开关占满行宽，保持展开时禁用收起延迟；字号提供实时样例。人物像列表选中/悬停使用中性色，资料库和编辑区各自明确分区。服务页标题固定，连接表单在内容区滚动；切换通道重建内容后恢复到对应选项的键盘焦点。

语言切换后键盘焦点留在重建后的语言下拉框；页面离开清理同样适用于语言重建。程序切页时若焦点仍在旧内容内，先移到目标侧栏，避免焦点引用已移除的视图。通用页每次进入重新读取持久化的字号、行为开关和自动连答上限；服务供应商切换后焦点回到供应商选择器。人物像帮助示例随中英日界面语言切换，用户输入不翻译。

外观入口已合并到通用页，不再提供强调色选择。通用页依次分为作答方式、答案呈现、应用偏好三组，固定页眉下滚动内容，保持原有控件尺寸与留白。作答方式合并思考档位、截图目标、连答上限和自动复制；截图目标、连答上限与界面语言采用相同的左右行布局。字号、推理默认展开、保持展开和收起延迟统一位于答案呈现，两条滑杆与数值列对齐，保持展开位于依赖它的收起延迟之前。切页保留滚动位置，控件获得键盘焦点时自动滚动到可视区域；切换语言后恢复嵌套语言控件的焦点及可见性。「答完后自动复制答案」位于通用页的捕获与作答分区，继续使用既有偏好值。历史主题数据保留兼容，不因设置页调整主动清空。


设置视觉回调：保留当前五页与选项归属，通用以三块紧凑浅色分组容器组织作答方式、答案呈现与应用偏好，控件和说明内缩到容器网格。共享分区标题取消编号与通栏线；思考选项缩短高度但保留副说明、方向键和焦点反馈。参考 output/settings-craft/01-general-before.png 的分组关系，不恢复历史账户行为。

其余设置页沿用相同分组底面：账户按体验、订阅、额外用量、恢复组织，订阅状态变化时同步更新容器与后续区域的位置。快捷键按捕获与会话控制分组；人物像保留资料库和编辑器双栏，空状态不展示空分组。服务页根据通道动态生成连接分组，更新操作独立成组。底面为不可交互装饰，原有键盘、点击、状态保存与业务流程保持不变。

账户异步操作完成后，若原操作被状态切换隐藏，焦点转至同区仍可用的管理/订阅/刷新按钮。体验开始按钮消失后焦点可转至刷新；取消续费弹窗返回时恢复操作焦点。异步等待期间已切页或转到其他控件时，不把焦点抢回原操作。账户订阅卡片增减高度时保持后续区域间距，并同步文档高度。

自动连答上限选项为 5、10、20、30、50、100 题和无限。默认仍为 20；修改从下一次会话生效。无限仅取消每次会话的题数停止条件，进度显示已答题数/∞；不会绕过账户用量、凭证校验、失败、空闲超时或手动停止。
