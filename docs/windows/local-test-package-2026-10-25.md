# Windows 本地报告测试包

用户选择：只在测试电脑本地收集，正常退出时生成 ZIP，由测试人员转发；不自动上传诊断。本次不推送、不发布、不合并 main、不安装工具。

测试构建通过 `npm --prefix desktop run pack:win -- --local-test` 启用；普通包行为不变。复用已缓存的固定版 Windows x64 Electron，Apple Silicon 产出便携 ZIP，不制作 NSIS 安装器。测试包不签名、不注册正式版协议、不启用发布/自动更新配置。

测试版启动时告知采集范围，使用独立的 `NotchSPI-LocalTest` 用户数据目录。诊断上传被主进程强制关闭，不依赖用户是否点击设置开关；正常查题仍会按用户所选服务发送题图并可能消耗额度，不能把「本地诊断」理解成「离线查题」。

自动记录：版本、源码版本、系统版本、架构、显示分辨率与缩放、GPU 合成状态、固定枚举的操作/结果/错误原因、耗时、CPU 和内存采样。不记录题图、答案、提示词、窗口标题、文件路径、账户凭证或原始异常文本。每次会话最多保留 2000 条事件，丢弃数在报告中说明。内存和 CPU 是进程级采样，不等于动画帧率证明。

从托盘退出会自动生成 ZIP 并打开所在文件夹；正常退出路径已通过 Mac-host Electron 实跑。强制结束/崩溃时保留 pending 日志，下次启动补出 interrupted 报告。报告在 Windows 用户数据下的 `NotchSPI-LocalTest/reports`。报告无自动上传代码，测试者只需转发 ZIP；不需要开发工具或手动收集日志。

验证包括 ZIP 读取/内容过滤、意外退出恢复、本地模式实际启动退出、桌面 check、设置和日常回归、打包后 ASAR/ZIP 内容与源码逐字节核验。Windows 实机运行、系统提示、真实截图排除、穿透、GPU、帧率仍待验收；不能因自动报告生成就宣称全部通过。
