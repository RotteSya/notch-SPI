# 账户、订阅与设置对齐 — 2026-10-25

## 基准确认

用户指出首次打开的旧引导 QA 包不是最新版，该包已退出，未据其六页设置结构修改代码。随后用户亲自打开正式设置，实际读取五页结构：通用、快捷键、账户与订阅、人物像、服务与模型。正式运行实例为 Applications 中的 NotchSPI 3.0（27）；实际控件和当前 MainSettingsWindow 的五页结构吻合。

正式版开启截图排除，截图返回白图；没有关闭保护。截图参考另由本轮 `.build/debug/NotchSPI` 组装独立 Settings Reference 包，未安装或替换正式 App。一般设置参考只使用独立临时凭据；账户的明确离线参考追加 `NSPI_QA_BALANCE=300`，其账户/订阅逻辑禁止真实请求。不能把最初未带该参数的参考账户页宣称为全程无网络。

## 本轮实际修改

- `desktop/ui/account.mjs`：账户采用“你的体验 / 订阅计划 / 额外用量 / 账户与恢复”结构，按服务端 allowance_sources 分别展示免费、Plus、题包、其他余额，不从异步总余额自行相减。订阅有效时展示到期或续费时间、每日余额与进度；付款异常提供更新支付方式；待付款提供继续付款；取消续费后隐藏重复取消入口。按钮的购买/管理显隐同时参考 can_manage 和 billing_status，与原生规则对应。
- 题包改为下拉选择后“购买所选题包”；没有价格目录时禁用。外部答题通道仍显示订阅，但禁用官方题包自动使用选项。余额未知不显示为零。
- 恢复码和恢复账户改为模态入口；关闭时清空临时字段并返回触发按钮。凭证不存在时不提供保存恢复码入口。未用真实账户执行领取、购买、取消、恢复或展示恢复码。
- `desktop/ui/app.mjs`：侧栏使用五个单选导航项，支持上下键；切页淡入 120ms，减少动态效果时不播放；保存各页自己的滚动位置，返回时恢复。订阅操作被替换时焦点按管理、购买、刷新顺序转移；操作忙碌后恢复原入口。设置页 Esc 不再取消后台题目。服务来源改为选择卡片，CLI 依账户能力显隐；编辑在变更后保存，移除官方通道的空“保存”按钮。
- `desktop/ui/style.css`：对齐侧栏行高和分组间距、标题位置、账户卡片宽度与高度、订阅主操作与进度条；保持可滚动布局。
- `desktop/main.mjs`：设置窗口保持 850×620、固定尺寸，重开时激活已有窗口。设置窗口纳入现有截图排除注册，原生宿主正常模式也保持内容保护。账户操作串行防重入，错误留在账户页，不把支付错误变成解题错误。刘海透明和鼠标穿透实现未改。
- `desktop/ui/i18n.mjs` 补页面说明和通道说明；`desktop/package.json` 增加 settings 冒烟入口。无依赖安装或升级。
