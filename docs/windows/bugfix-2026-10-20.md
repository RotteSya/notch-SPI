## 修复行为

| 问题 | 本次改动 |
| --- | --- |
| 鼠标移出刘海不收起 | 主进程每 50 ms 读取系统鼠标位置，转换为窗口坐标，弥补透明窗口丢失 DOM 移出事件的情况。移出后按 Mac 的 450 ms 收起，重新进入会取消；引导、菜单、预览和收集题图期间保留相应交互。结果展示仍使用用户设置的阅读延迟，0 表示不定时收起。 |
| 截图带上刘海 | 本应用取帧前隐藏刘海并暂停飞入窗口，等待合成器更新后再截图，最后恢复。并发截图共用隐藏区间；错误也会恢复；用户主动隐藏或已销毁的窗口不会被重新打开。 |
| 设置窗口截不到 | 截图保护限定于刘海和飞入层；设置、历史窗口不再启用保护。受保护窗口显示时重新应用保护属性。 |
| 设置窗口不能拖动 | 增加顶部 30 px 拖动区，设置标题和侧栏品牌也可拖动；按钮、链接和输入控件保持可操作。 |
| 账户与订阅一直待核对 | 打开账户页、切入该页或重新聚焦时自动读取，合并同时发生的刷新。显示读取中、真实余额或错误及重试入口；订阅读取失败独立提示，不把失败当作未订阅。保留凭据，不自动领取体验或购买。 |
| “核对结算”用途不清 | 改为“查询本次扣次”，增加说明，仅在已有且未过期、属于当前账户的官方请求发生异常或取消时显示。只查询原请求，不重发查题、不再扣次。 |

## Windows 实机仍需检查

使用下方更新后的 ZIP，在正常交互桌面验证：

1. 鼠标移出刘海、快速跨屏、返回刘海、关闭菜单/预览；阅读延迟、收集题图及引导不被意外打断。
2. 设置页的顶部和标题拖动，按钮/输入不触发拖动，Windows 标题栏按钮可用。
3. 设置窗口保持在屏幕中，展开刘海后单图/连续多图截图：题图包含设置窗口，不含刘海、预览或飞入层；失败后窗口恢复，主动隐藏后不自动打开。
4. 自动连答取帧时的窗口隐藏/恢复是否产生可见闪烁；连续截图期间的飞入衔接；多屏和不同 DPI。
5. Win+Shift+S 等外部截图工具对受保护刘海和普通设置窗口的行为。
6. 在原 Windows 账户上自动读取、断网重试、账户恢复、异常请求的“查询本次扣次”。本轮未读取用户真实账户，也未进行真实付费查题。

上述需要 Windows 图形会话；本机 ZIP 构建、ASAR 核对和 macOS 上的 Electron 运行不能代替。
