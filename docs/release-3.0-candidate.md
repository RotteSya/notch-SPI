# 3.0 候选验收与发布准备

本轮只准备候选，不执行生产部署、正式 Release、推送标签或修改生产 Stripe 设置。

## 产品约定

- Plus：CNY 69 / 月、自动续费、每日 400 次，北京时间零点重置。取消续费保留已付款周期；续费失败不延长权益。
- 免费体验：72 小时、每日 400 次。新手引导可稍后领取，设置 → 账户与订阅长期保留符合资格账户的领取入口。领取成功才开始计时。
- 体验与 Plus 独立计额，按体验 → Plus → 题包顺序使用；购买不会提前开始免费体验。
- 3.0 / build 26。Plus 集中在设置的「账户与订阅」页；旧离线月票样例不是正式购买路径。

## 3.0 主要更新

- 最近查题：本机保存成功答案与题图，支持回看、复制和删除，回看不重复扣次。
- 答案阅读：SwiftMath 公式、长答案与解释显示、连续阅读和滚动改进。
- 截图与刘海：多图收集、预览暂停、撤销、取消与失败恢复，以及显示器变化、唤醒和全屏切换适配。
- 官方服务：DeepSeek 思考强度、思考活跃信号、复杂答案输出与截断处理。
- 账户与支付：可延后领取的 72 小时体验，以及本轮新增 Plus 月订阅。
- 应用更新：可取消下载、安装校验和新版启动确认。

## 已做的审查修正

- 官网三语补充最近查题题图/答案本机保存、30 天/100 条/200 MB 和访问时清理规则，区分 15 分钟临时材料。
